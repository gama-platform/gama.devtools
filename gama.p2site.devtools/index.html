GAMA Developer Tools

This is an Eclipse update site. It is meant to be used from Eclipse, not browsed.

The GAMA Developer Tools add a GAMA menu to the Eclipse IDE used to develop GAMA. They provide:

  • Get started..., a guided setup from prerequisite checks through source installation and building to launching GAMA;
  • wizards for new GAMA plugins, skills, operators, actions, types and test models;
  • Clean GAMA plugins, a dialog-free clean and rebuild that resets the GAML annotation processor;
  • a configuration checker with quick fixes;
  • reports of undocumented and untested GAML elements.

Installation

For GAMA development, use Eclipse IDE for Java and DSL Developers 2026-03 or newer, with JDT, PDE and Xtext/MWE2, running on Java 21 or newer. A separate full JDK 25 is needed to compile and launch GAMA; Eclipse can keep using its bundled Java runtime.

  1. In Eclipse, choose Help > Install New Software...
  2. Click Add... and enter https://gama-platform.org/gama.devtools/ as the location.
  3. Select GAMA Developer Tools, then finish the wizard and restart Eclipse.

Getting started

Recommended: accept the setup prompt after restarting in a workspace without a gama.core project, or choose GAMA > Get started.... The wizard checks Eclipse, helps register JDK 25, opens the core and optional source installers, cleans and builds on request, then offers Run, Debug or launch-configuration creation only.

It does not download and install Eclipse components or the JDK for you, nor install missing target-platform dependencies. Checks link to the relevant downloads and Eclipse settings. The startup prompt can be disabled per workspace in Preferences > GAMA Developer Tools.

Manual alternative: configure JDK 25 in Java > Installed JREs and its execution environments, install or import the sources, resolve dependencies against the running Eclipse, use GAMA > Clean GAMA plugins and Check workspace..., then configure and run the GUI through GAMA > Run GAMA. See the guided and manual setup instructions for the complete steps.

Use GAMA > Update GAMA tools... for developer tools updates, or Eclipse's Help > Check for Updates.

The stable address above is a composite update site. Previous builds are retained at versioned addresses so that installations started before an update can still download their artifacts.

The update site is rebuilt every time the developer tools change on the main branch. See the README of gama.ui.devtools for more information.
